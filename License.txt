This comprehensive package.json and supporting files provide:

**Features:**
1. **Build System**: Rollup with TypeScript and Babel
2. **Testing**: Jest with React Testing Library
3. **Code Quality**: ESLint, Prettier, TypeScript
4. **Documentation**: Storybook integration
5. **CI/CD**: GitHub Actions workflow
6. **Version Management**: Semantic versioning scripts
7. **Peer Dependencies**: React and React Native support
8. **Type Safety**: Full TypeScript support
9. **Bundle Optimization**: Tree-shaking and minification
10. **Publishing**: Ready for npm publishing

**Best Practices:**
- Modern build tools (Rollup)
- TypeScript for type safety
- ESLint and Prettier for code quality
- Storybook for component documentation
- Jest for testing
- CI/CD pipeline
- Semantic versioning
- Tree-shaking support
- React and React Native compatibility
- Easy to consume and extend
